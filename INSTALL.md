# Install Cards

After [setting up PrimitiveOS](https://github.com/DoanNguyenTrong/kindle-primitive-launcher/blob/main/docs/INSTALL.md#first-time-setup-over-usb), open **Store** from Primitive Launcher.
Select **Cards** under **Apps**, tap **Get**, then open it from the Launcher grid. For an installed copy, open **Updates** in Store.

For a local USB test, extract the package for your Kindle, copy the `cards` and `documents` folders to user storage,
eject, and open Cards from Primitive Launcher. The app uses the launcher's fonts. The Done button returns you
to the launcher.
